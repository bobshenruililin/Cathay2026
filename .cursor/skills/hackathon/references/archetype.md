# Archetype × clock (any hackathon)

Two axes. Do not write a 50-page event wiki. Fetch T+0 in `recon`; this
file is a **prior** for how modes map, not gospel for dates.

## Who scores (archetype)

| Archetype | Room | What they remember | Reconnect analogue |
| --- | --- | --- | --- |
| Table-surprise | Tired 24h judges, public expo | One hallway noun + a working click | Not this host |
| Stampede video | Huge MLH / Devpost field | Trailer; overall is a lottery | Prize math still one path |
| Corporate bonus-stake | BUs in the room | Feasibility + adoptability + named owner | **Cathay 2026** |
| Onchain + disclosure | Judges + public repo ethics | Honest LIVE vs seeded; no fake TVL | Honesty still required |
| MLH honesty | Student weekend, published rubric | Feature Zero by ~15% of the clock | Feature Zero here already shipped |

If the first noun is “AI / agent / dashboard”, `identity` rewrites. No code.

## How time is shaped (clock)

| Clock | Feature Zero | Legal modes early | Legal modes at freeze |
| --- | --- | --- | --- |
| 24h / 36h / 48h | Build it by ~15% of the clock, then **stop** | `identity` then build one object | `stop` `claims` `90s` |
| Async week | Same, stretched | `recon` if rules still moving | `stop` `90s` |
| **Gated-then-sprint** | Often already exists; the **gate is the product** | `apply` + `recon` only | `stop` `identity` `claims` `90s` |

Cathay 2026 = **corporate bonus-stake × gated-then-sprint**.
27 Sep application is the first product. 14–16 Nov is freeze, not a rebuild.

Do not run a 24h “ship Feature Zero” playbook on a gated event whose demo
path already exists. Do not run `apply` during the freeze weekend.

## Prize math (every event)

Overall in a stampede is a lottery. Pick **one primary** and at most **one
piggyback** on the **same** object. A second spine “for the other prize”
is how you lose the hallway noun.

## Human freeze (every event)

Agents may **cut**. They may not replace the problem. Only a human unfreezes
scope in writing. Mixing scout modes into freeze weekend is how you lose.

## Refuse on every event

Builder swarm; champion-named workers with feature branches; `/pitch` or
`/demo` as extra skill packages; slide factory; auto-submit; promising a
win; seventh demo step; LLM as the decision core; copying last year’s trophy.
